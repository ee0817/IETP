# 检测要求
用简单的启发式规则判断 chunk 是否可疑：
1. 长度异常：content 长度小于 10 或大于 5000 字符 → 加分。
2. 重复字符：连续重复字符（如 "aaaaa"）超过 20 个 → 加分。
3. 特殊字符比例：非字母、非汉字、非标点的特殊符号（如控制字符）占比超过 30% → 加分。
4. 元数据缺失：metadata 为空字典，且 source_id 为 "unknown" → 加分。
5. 得分累加后，最高 1.0，最低 0.0。
6. 得分 > 0.5 时，risk_type 为 "poisoned_document"，否则 "none"。

# 输出要求
返回 SecurityEvent：
- event_id: uuid.uuid4().hex
- chunk_id: chunk.chunk_id
- stage: "retrieval"
- risk_type:
  - 得分 > 0.5："poisoned_document"
  - 否则："none"
- risk_score: 上述累加得分，范围 0.0~1.0
- confidence:
  - 得分 > 0.5：0.7
  - 得分 <= 0.5：0.9
- 必须包含 event_id 和 chunk_id。
