# 一、白名单实现要求（checks/whitelist_check.py）
实现函数：
def is_whitelisted(source: str) -> tuple[bool, str]:
    """
    检查 source 是否命中白名单。
    返回 (是否命中, 命中的规则描述)
    如果 source 为 "unknown" 或空字符串，直接返回 (False, "")。
    """

匹配规则（从 config/whitelist.yaml 读取）：
- 域名后缀匹配：source 的域名以白名单域名结尾。例如白名单为 internal.company.com，则 source=https://internal.company.com/doc 命中。
- URL 前缀匹配：source 以白名单前缀开头。
- 精确匹配：source 与白名单条目完全相同。

防绕过要求：
- 域名匹配时，必须校验边界。例如 internal.company.com 不能匹配 internal.company.com.evil.com。
- 建议用 urllib.parse.urlparse 解析域名后再比较，不要简单用字符串 in。

配置文件 config/whitelist.yaml 格式：
version: 1
rules:
  - type: domain_suffix
    value: "internal.company.com"
    note: "公司内部知识库"
  - type: url_prefix
    value: "https://trusted.wiki.org/"
    note: "可信外部 Wiki"
  - type: exact
    value: "https://approved.example.com/doc-001"
    note: "已审核文档"
