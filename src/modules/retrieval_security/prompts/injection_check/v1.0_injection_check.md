# LLM Guard 集成要求
1. 引入库：
```python
try:
    from llm_guard.input_scanners import PromptInjection
    from llm_guard.input_scanners.prompt_injection import MatchType
    LLM_GUARD_AVAILABLE = True
except ImportError:
    LLM_GUARD_AVAILABLE = False
```
2. 初始化扫描器（在文件顶部全局初始化，或使用单例模式，避免每次调用都重新加载模型）：
```python
if LLM_GUARD_AVAILABLE:
    try:
        scanner = PromptInjection(threshold=0.5, match_type=MatchType.FULL)
    except Exception:
        LLM_GUARD_AVAILABLE = False
```
3. 检测逻辑：
   - 如果 `LLM_GUARD_AVAILABLE` 为 True，调用 `scanner.scan(chunk.content)`。
   - `scan` 返回 `(sanitized_text, is_valid, risk_score)`。
   - 如果 `is_valid` 为 False，说明有注入风险，`risk_type` 为 `"prompt_injection"`，`risk_score` 取返回的值（或映射到 0.8~1.0 之间），`confidence` 设为 0.9。
   - 如果 `is_valid` 为 True，说明无风险，`risk_type` 为 `"none"`，`risk_score` 为 0.0，`confidence` 为 1.0。
   - 如果 LLM Guard 执行过程中抛出异常，捕获异常并自动降级到正则规则。

# 正则规则降级要求（Fallback）
1. 保留 V0.1 的 6 条模式，定义为一个常量列表 `FALLBACK_PATTERNS`。

3. 命中时 `risk_score` 给 0.9，`risk_type` 为 `"prompt_injection"`，`confidence` 为 0.9。
4. 未命中时 `risk_score` 给 0.0，`risk_type` 为 `"none"`，`confidence` 为 1.0。
