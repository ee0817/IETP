# 检测要求
用简单的字符串包含或正则匹配 chunk.content，覆盖以下几条最典型的注入模式即可：
1. "忽略以上指令"
2. "忽略之前的指令"
3. "ignore previous instructions"

5. "输出系统提示词"

# 输出要求
返回 SecurityEvent：
- event_id: uuid.uuid4().hex
- chunk_id: chunk.chunk_id
- stage: "retrieval"
- risk_type: 命中时 "prompt_injection"，未命中时 "none"
- risk_score:
  - 命中任意一条：0.9
  - 未命中：0.0
- confidence:
  - 命中：0.9
  - 未命中：1.0
